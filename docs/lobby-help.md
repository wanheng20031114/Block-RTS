# 大厅与房间

在主菜单选择“单人遭遇战”，再选择 **1v1、2v2、3v3、4v4、2v2v2 或八人乱斗**，设置“电脑难度”，点击“开始单人遭遇战”即可进入。单人模式不需要网络，所选难度适用于本局所有电脑盟友和对手，并保存在本机。

电脑难度为 **普通 / 困难 / 极难 / 噩梦**，农民每次采集金币分别为正常的 **1 / 2 / 3 / 4 倍**，即每次 **4 / 8 / 12 / 16 金币**。困难起有额外采集收益；人口上限、生产和研究费用、视野以及每秒自然收入仍遵守正常规则。采矿科技只加快采集周期。真人断线后的电脑接管仍按普通收益计算。

点击“多人对战”展开房间面板。填写昵称，使用随游戏提供的服务器地址，或者输入自己的兼容房间服务器地址。在“房间规模”中选择所需模式，然后点击“创建房间”。房主可以将八位邀请码复制给朋友；其他玩家输入邀请码后加入。房间创建后模式固定，离开房间后可以重新选择。

**2v2 默认席位 1、2 为同队，席位 3、4 为另一队**。房间上方直接显示各联盟参战人数。房主可以用每行的联盟菜单调整队伍，各队人数可以不同，但不能超过所选模式的每队上限。

房主可直接点击空席上的“添加电脑”，或点击“为全部空位添加电脑”。补齐操作只处理空位，不会替换真人。每个电脑席位有独立难度下拉菜单，所有玩家都能看到难度和采集倍率，只有房主可以修改；“移除电脑”可重新腾出位置，让朋友加入。席位或难度修改等待服务器确认时，相关按钮会暂时禁用。

**一位房主加三位电脑就能开始 2v2，无需再等待真人**。也可以保留空位，至少两个敌对阵营参战、加入的真人都准备就绪后即可开始。房主默认就绪，电脑自动就绪；席位、队伍或电脑难度变化时，其他真人需要重新准备。

连接失败会在面板底部说明原因。可以重试，或者直接开始单人遭遇战。昵称和公开服务器地址会保存在本机；大厅不会保存或显示服务器管理凭据。

主菜单的“设置”可以调整显示、声音、镜头和热键。普通对战中默认按 F5 打开战场菜单，也能进入同一设置界面。窗口模式、分辨率、垂直同步与帧率上限会保存到本机；更改显示设置后，15秒内点击“保留设置”，否则恢复先前画面。声音页可调整总音量、总静音，以及独立的背景音乐开关和音量。

热键页可以分别调整各项操作。生产、建造与研究使用当前面板的槽位，默认从左至右为 Q、W、E、R、T、Y；翻页后以当前按钮角标为准。按钮角落、帮助和编队提示会跟随绑定更新。完整操作见[玩家指南](windows-readme.txt)。

单人遭遇战按 F5 暂停/继续。联机 F5 的全局暂停由房主控制，普通玩家只打开或关闭本地菜单；Esc 用于取消指派或队尾生产/研究。双方的颜色按每个观看者区分：自己蓝色、队友黄色、敌人红色；颜色只影响辨识，不改变单位所有权。

沙盘拥有英雄时，F5 用于切换俯视与第一人称，第一人称下按 Esc 打开菜单。“设置 → 第一人称”可调整视野角、鼠标灵敏度和镜头运动。
