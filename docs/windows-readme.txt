Block-RTS · 玩家指南

启动游戏
完整解压 windows 文件夹，双击“Block-RTS.exe”。EXE 与 PCK 必须来自同一个发布包，并留在同一目录。
当前版本可在主菜单查看。FONT_LICENSE.txt 是随包字体的许可，请保留。
本产品使用独立的 Block-RTS 用户目录；首次运行从原“积木争霸”复制设置、大厅偏好和远征存档。已有新配置时不覆盖，原数据保留。

选择玩法
单人遭遇战：与电脑对战，可选择对战规模与难度，无需联网。
多人对战：创建房间，将邀请码发给朋友；也可以添加电脑填补空位。
林海远征：带领一支小军团探索森林，通过战斗、招募和收藏品逐步成长。目前开放单人第一层。
自由沙盘：自由摆放单位与建筑，观察战斗，也可以创建自己的英雄。
战争图鉴：按分类查看单位、建筑与科技，了解数值、克制关系和动作。

对战操作
左键选择，拖框多选，右键移动或攻击；按住 Shift 追加命令。
中键拖动、方向键或屏幕边缘平移视角，滚轮缩放，空格定位选中对象。
B 选择大本营，F2 或 G 选择全部己方战斗单位，句点选择空闲农民。F1 查看完整操作说明。
生产、建造与研究的快捷键以当前按钮角标为准。加入训练或研究队列时扣费，取消后退款。
普通对战中，摧毁敌方所有军事建筑即可获胜。自己的部队为蓝色、队友为黄色、敌人为红色；同队共享视野，不能控制盟友单位。
以上为默认按键，可在“设置 → 热键”中调整。F11 切换全屏，M 静音，F10 隐藏界面。

暂停与设置
普通对战中，默认按 F5 打开战场菜单；单人遭遇战同时暂停，联机的全局暂停由房主控制，其他玩家只打开本地菜单。
主菜单和战场菜单都可以进入设置，调整显示、音效、镜头和按键。
更改显示设置后，请在 15 秒内选择“保留设置”，否则会恢复先前画面。
沙盘拥有英雄时，F5 用于切换俯视与第一人称；第一人称下按 Esc 打开菜单。

英雄与第一人称
在“自由沙盘 → 我的英雄”中设置名字、外观与队伍。英雄目前只在沙盘开放。
俯视时像普通单位一样选择和下令；按 F5 切换到第一人称，使用准星自由瞄准。
第一人称：WASD 移动，左键开火，R 换弹，空格跳跃，I 打开背包，1—5 使用快捷栏物品。
射击可能打空，障碍物可以挡住子弹。跳跃不能越过障碍或躲避攻击。
“设置 → 第一人称”可调整视野角、灵敏度与镜头运动；默认保持平稳视角。

林海远征
开始远征时先选择战略，再选择初始军队。初始出战人口上限为 20，未上阵的部队可以留在军团中。
点击相邻地点可先预览，再确认前往；每次移动消耗行动力，原路返回也会消耗。
金币用于购物，面包用于招募。可在商店购买招募券与收藏品，也可以处理不期而遇、在营地补给和调整编队。
运营与战斗分开进行：进入战斗后，不能采矿、建造或招募。
前哨站需要消灭全部敌方建筑与部队。行动力耗尽并完成当前节点后，会触发围剿，可以先整理军队。
围剿中保护中央大本营 150 秒；士兵全灭仍可坚守，大本营被毁则失败。成功突围并确认结算后，保存军团进度，完成第一层探索。

远征存档
完成并离开节点时自动保存；创建新远征、完成围剿结算，以及地图上确认招募或调整阵位时也会保存。
中途退出后，可从最近存档点继续。当前战斗和节点内尚未保存的进度不会保留。
失败后可以读档再次挑战；已触发的围剿不会因读档而取消。
“开始新远征”会覆盖当前远征存档，游戏会先询问确认。存档保存在本机。

多人对战
支持 1v1、2v2、3v3、4v4、2v2v2 和八人乱斗。房主可以调整队伍、添加电脑或保留空位。
至少有两个敌对阵营参战，且加入的真人都准备就绪后，房主即可开始。
断线后可在宽限期内重连。房主断线时，对局等待房主重连；不会自动更换房主。
请让所有玩家使用同一个完整发布包。若提示版本或内容不匹配，请更新到与房间服务器兼容的发布包。

遇到问题
可双击 COLLECT_DIAGNOSTICS.cmd，在“文档/Block-RTS-诊断”生成本地 ZIP，便于反馈问题。
诊断包包含日志、近期相关 Windows 错误、显卡和系统信息及游戏文件校验值，不会自动上传。
